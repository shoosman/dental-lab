# Журнал зуботехнической лаборатории

Веб-приложение (PWA) для учёта хода работ: что сдать сегодня, напоминание на 1–2 дня вперёд,
ближайшие дни и календарь с цветом нагрузки (1 работа — зелёный, 2–3 — жёлтый, 4 и больше — красный).

- **Где живёт:** GitHub Pages, `https://shoosman.github.io/dental-lab/`.
- **Установка:** iPhone — Safari → «Поделиться» → «На экран «Домой»»; Android — Chrome → «Установить приложение»;
  Mac/ПК — Chrome «Установить приложение» или Safari «Файл → Добавить в Dock».
- **Обновления:** правка → `git push` → через 1–2 минуты все устройства сами подхватят новую версию
  (приложение сверяет ETag страницы при открытии и раз в 30 с; service worker — network-first).
  Номер версии вручную менять не нужно.

## Синхронизация

Как в «Считалке»: данные — JSON-файл `dental-lab-orders.json` в секретном GitHub Gist владельца,
локальная копия — `localStorage` (работает без сети).

- Токен: github.com/settings/tokens → Generate new token (classic) → No expiration → только скоуп **gist**.
  Один и тот же токен вводится на каждом устройстве (кнопка «☁» в шапке).
- В отличие от «Считалки», слияние **по каждому заказу** (побеждает более поздний `updatedAt`),
  удаления хранятся «надгробиями» 60 дней — одновременные правки с двух устройств не затирают друг друга.
- Сверка: при открытии, при возврате в приложение, раз в 30 с, через 1,5 с после правки и при сворачивании.

Секретный гист не зашифрован: его нельзя найти поиском, но он открывается по прямой ссылке.
Токен со скоупом `gist` даёт доступ ко всем гистам аккаунта — давайте его только тем, кому доверяете.
